# 联合项目结构与开发入口

## 实际目录

```text
D:\script-dev\yys-script-dev\
├─ oas\                         # OAS Python 服务端真实代码副本
│  ├─ module\                   # 通用框架、设备、OCR、服务端接口
│  ├─ tasks\                   # 阴阳师任务和业务逻辑
│  ├─ config\                  # 配置与部署设置
│  ├─ tests\                   # Python 测试
│  ├─ .venv\                   # 本地 Python 3.10 环境，已迁移，未纳入 Git
│  └─ server.py                 # Web 服务入口
├─ oasx\                        # OASX Flutter 客户端真实代码副本
│  ├─ lib\                     # 页面、控制器、API、WebSocket
│  ├─ windows\                 # Windows runner
│  ├─ assets\                  # 客户端资源
│  └─ pubspec.yaml              # Flutter 依赖
├─ docs\                       # 开发文档和分析文档
└─ README.md
```

## 分工

OAS 负责 Python 服务端、调度器、任务执行、截图/OCR、配置和日志。
OASX 负责 Flutter 页面、用户操作、HTTP/WebSocket 调用和数据展示。

OASX 的页面布局在 `oasx/lib/views/` 和相关 Dart 文件中；任务菜单、配置字段、运行状态和日志内容由 OAS 服务端接口提供。

## 开发启动

```powershell
cd D:\script-dev\yys-script-dev\oas
.\.venv\Scripts\python.exe server.py --host 127.0.0.1 --port 22267
```

然后在 OASX 登录页输入 `127.0.0.1:22267`。开发客户端可运行：

```powershell
cd D:\script-dev\yys-script-dev\oas
cd ..\oasx
flutter pub get
flutter run -d windows
```

## 迁移原则

两个项目已经复制为新根目录下的真实目录，旧目录仍保留作为回退。旧仓库的 `.git` 未复制，新根目录已初始化独立 Git 仓库但没有提交。日志、Flutter 构建目录和缓存不纳入 Git；OAS 的 `.venv` 保留在本地供运行使用。
